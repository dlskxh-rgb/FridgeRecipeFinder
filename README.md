📌 About the Project

FridgeRecipeFinder is a lightweight recipe recommendation application.

Users can add ingredients from their fridge and receive recipe suggestions based on ingredient matches.

The project is designed as a simple client-side application and does not require a backend server.

All user data is stored locally in the browser using LocalStorage.

---

✨ Features

🥕 Ingredient Management

Users can:

- Add ingredients
- Remove ingredients
- Prevent duplicate ingredients

🍳 Recipe Suggestions

The application compares the user's ingredients with available recipe data.

Recipes are sorted based on the number of matching ingredients.

⭐ Favorite Recipes

Users can add recipes to their favorites list.

Favorite recipes are saved locally.

💾 Local Storage

The following data is stored in the browser:

- Ingredients
- Favorite recipes

Data remains available after refreshing the page.

⚙️ How It Works

1. Add ingredients that you currently have.
2. Click Find Recipes.
3. The application compares your ingredients with the recipe database.
4. Recipes with more matching ingredients are displayed first.
5. Add your favorite recipes to the favorites list.
